Docker & Docker Compose: Docker builds isolated containers from images, 
packaging an app with its dependencies. Docker Compose orchestrates 
multiple containers (defined in a docker-compose.yml) so they run together 
as one coordinated service.

Image with/without Compose: The image itself is the same either way, 
but without Compose you run/configure each container manually via docker 
run and flags. With Compose, configuration (networking, volumes, env vars, 
dependencies) is declared in a file and applied automatically.

Docker vs VMs: Containers share the host's kernel, making them much 
lighter and faster to start than VMs. VMs virtualize full hardware with their 
own OS, using far more resources.

Directory structure: An organized structure (e.g. separate folders per service, 
each with its own Dockerfile) keeps the project clear and helps Compose find 
build contexts correctly. Following it also makes grading/review easier, 
since it matches the expected format in the subject's PDF.

- Docker network
A Docker network is an isolated virtual network created by Docker, where 
containers can communicate with each other using the service name as a 
hostname — without needing to expose ports externally or know each other's IPs.
